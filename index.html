    — Area: —

    MorphoTrace — help

    Draw (D): add area

    • Click add a vertex (also inside an existing area)
    • Shift+drag trace freehand
    • Click the first vertex, Enter or double-click to close
    • A polygon closed over an existing one merges with it
    • Alt+first click: subtract this one polygon
    • Right-click or Backspace remove last vertex · Esc cancel

    Subtract (S): remove area

    • Draw (red trace) over the part to remove
    • A polygon fully inside an area makes a hole

    Edit (E)

    • Hover an area (it highlights) and click to select it · Del delete it
    • Drag a vertex to move it
    • Double-click a contour line to add a vertex there
    • Hover a vertex (it grows) and right-click, or Alt+click, to delete it
    • H turn the selected polygon into a hole (advanced)

    View

    • Shift+wheel: zoom at cursor · +/− zoom in/out
    • F or 0 (or click the zoom %): fit to window · 1 (or double-click it): 100%
    • Wheel (vertical / horizontal): scroll the image
    • Space+drag or right-drag: pan
    • ←/→ previous / next image · G (or click the counter) go to image number
    • X mark image unusable (with reason)

    Measurement

    Area is computed exactly from the polygon vertices (shoelace formula, holes subtracted) and also from the rasterised binary mask. Physical area uses the scale field: mm² = px × (µm/px)² / 10⁶.

    Work is autosaved in this browser. Export JSON regularly as a backup.
